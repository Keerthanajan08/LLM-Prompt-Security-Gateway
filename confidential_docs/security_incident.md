# Incident Report INC-2291 (CONFIDENTIAL, fabricated demo data)

On September 3 an attacker used a leaked contractor VPN credential to access the staging environment for about six hours before detection.

The attacker exfiltrated a copy of the staging database, which contained names and email addresses of roughly 12,000 customers. Payment data was not affected.

Customer notification has not yet been sent; legal is still assessing whether the breach meets the GDPR 72-hour reporting threshold.
